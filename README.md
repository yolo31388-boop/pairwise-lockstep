# pairwise-lockstep

联机对战改成帧同步后，不同设备跑十秒就 desync：逻辑帧用了 float 运算，x86 和 ARM 的舍入不一致；输入没有按玩家 id 排序，同一帧两个输入到达顺序不同；随机数种子只用了时间戳，回放时对不上；定点数乘法溢出后没有饱和，伤害计算出现负数；丢包重传把旧输入塞进未来帧，角色瞬移；帧率波动时逻辑帧被渲染帧带着走，追帧策略不一致。net/lockstep.py 是核心，tests/test_lockstep.py 15个红。要修的是：逻辑层全定点数；输入按 id 和帧号排序；种子由房间协商；乘法溢出饱和；旧输入丢弃并补空帧；逻辑帧与渲染帧解耦。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。

语言/框架：Python 3, pytest；环境可复现等级：无外部依赖。
